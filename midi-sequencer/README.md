# libs/midi-sequencer

The MIDI sequencer, on the generic one (`libs/sequencer/README.md`), the timeline (`libs/timeline/README.md`), MIDI's messages (`libs/midi/README.md`), `libs/automation/`, `libs/util/` and the clock: the input a control surface plays into, which alone plays the instruments, its messages MIDI 2.0's channel voice messages as values, each note a fresh index; the stream every play goes through; the recorder, what's heard kept as regions and lanes, and the recording player. A pattern's note (`PatternNote`: pitch, step, phrase, vibrato) and a pattern of notes (`NotePattern`: its rhythm's shape and vibrato) are the music's (`pattern-note.ts`). Pure: no Web Audio; its tests in its `test/` folder. Why it's built so: `mockup/architecture/sequencer.md`.

```js
import { Sequencer } from './index.ts';
import { NoteRotation } from '../midi/index.ts';
const sequencer = new Sequencer({ tracks: (name) => trackOf(name) });   // the input a control surface plays into, which alone plays the synths
sequencer.onPlay((play) => recorder.heard(play));                      // every play it passes on, into its own stream, for whoever listens
const index = rotation.noteOn();                                        // a fresh index for the note
sequencer.send({ track: 'tap', clip: owner, live: true }, [            // to its instrument at once, and into the stream
  { type: 'note on', index, pitch: 62, velocity: 1, t, part: 2 },
  { type: 'per-note controller', index, controller: 'volume', value: 0.4, t: now },   // how it's heard as it starts
  { type: 'note off', index, t: t + sixteenth },                        // its length known as it starts: sent with it
]);
sequencer.onNote((to, note) => light(to.clip, note.noteOn.part));       // the way back: each note as it's passed on
```
