# build/desk

A desk built and played by address, a package of its own since SHAPE1b2: what a desk does as it plays, on what any builder hands back (the ports' `Built`, `libs/build/ports/`), beyond it its ways in (`DeskBuilt`). The view models read it through a port of their own (`libs/view/models/`'s `deskPort()`). Its owner plans it (`libs/plan/desk/`), makes it once with its setup's rules and the clock, and hands it a function that builds the plan where it wants it: the app's builds it with the Web Audio builder, into an output that fades in (`libs/build/web-audio/`'s `AudioPower`). It knows no setup's names: a setup hands in its rules (`DeskSetup`). As a console, it has its own parts, made with it: its strips' controls, its tracks' channels, the live mix's mute and solo; its owner talks to the desk alone.

```ts
import { Desk } from './index.ts';
const desk = new Desk<WebAudioBuilt>({ plan, setup, clock, at });
desk.set(['tap', 'volume'], 0.5); // kept, told what's built once it is
desk.build((planned) => builder.build(planned, { into: output.node })); // the settings changed before in it, the mix applied
desk.inputOf('my tap/3'); // a track's instrument's way in, its channel its pool's copy, added the first time
desk.control('tap', { type: 'controller', controller: 'volume', value: 0.4, t }); // on time, gliding
desk.control('tap', { type: 'controller', controller: 'mute', value: 1, t }); // the live mix's, at its time
desk.mixState(); // { muted: Set {'tap'}, soloed: Set {} }
```
