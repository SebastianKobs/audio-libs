# libs/sequencer

Patterns played on the grid, after Ableton's session view. A **pattern** is a clip: `{ meter, bars, loop, notes }`, its time signature (the master's when it's left out), its length in bars, whether it loops, and its notes, each `{ start, duration, … }` in ticks, 96 to a quarter (`PPQ`), on the straight grid. A rest isn't stored: it's the gap between notes. What's played is kept as a **record**, which is a pattern too. Pure: no Web Audio, nothing of the app's. A package of its own since L1e (`mockup/architecture/plan.md`), moved out of `sound/`, on the timeline (`libs/timeline/`), its tests in its `test/` folder. It's given `rand()` and the clock's grid as functions, and draws from `rand()` in a fixed order, so a seeded replay is always the same. Why it's built so: `mockup/architecture/sequencer.md`.

```js
import { NoteRotation, Sequencer, patternOf, unmute } from './index.ts';
import { ReplayTracks } from './tracks.ts';
const notes = unmute(patternOf(flower.seq, cycle), at, Math.random);    // a replay: a run of the record, running silently where it was played
const track = replays.place(flower, notes[0].at, until);                // on one of its kind's replay tracks (tracks.ts)
const sequencer = new Sequencer({ instruments: (track) => instrumentOf(track) });   // the input a control surface plays into, which alone plays the synths
sequencer.onPlay((play) => recorder.heard(play));                      // every play it passes on, into its own stream, for whoever listens (L1b)
const index = rotation.noteOn();                                        // a fresh index for the note
sequencer.send({ track: 'tap', clip: flower, live: true }, [            // to its instrument at once, and into the stream
  { type: 'note on', index, pitch: 62, velocity: 1, t, part: 2 },
  { type: 'per-note controller', index, controller: 'volume', value: 0.4, t: now },   // how it's heard as it starts (G0b)
  { type: 'note off', index, t: t + sixteenth },                        // its length known as it starts: sent with it
]);
sequencer.onNote((to, note) => light(to.clip, note.noteOn.part));       // the way back: each note as it's passed on (G0e)
```

**Replay tracks** (`tracks.ts`): `new ReplayTracks()` gives a kind's pool, `{ tracks, place(owner, from, until) }`. `place()` puts a play on a track and returns its index: the track its owner played on last if that's free, else the lowest free one, else a new one. A track is free once the play it holds has died away (`until`), so it plays one at a time; tracks are never taken away.

Tested in node, in its `test/` folder since L1e (`test/sequencer.test.js`, `tracks.test.js`, `input.test.js`, `clips.test.js`, `recorder.test.js`, `playback.test.js`, `lane-playback.test.js`, `lane-values.test.js`); the garden's phrasing, what was here until L1a, in its own README (`garden-surface/phrasing/README.md`); what the garden plays through it is held to the replays' recordings, and its stream to the sequencer's vectors (`shared/test-vectors/replays/`, `sequencer/`).
