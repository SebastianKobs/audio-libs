# midi-devices

MIDI's devices: inserts on a track's notes, as an audio effect is an insert on its sound, as Ableton's MIDI Effects beside its Audio Effects. Part of [the libraries](../README.md).

- [`scale/`](scale/README.md): the Scale device, mapping each note into the key chosen.

Reads: `libs/base/` (`params`, `util`), `libs/midi/protocol/`, `libs/music/music-theory/`.
