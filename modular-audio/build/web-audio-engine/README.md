# build/web-audio-engine

The Web Audio builder run in a browser, on the one clock, so a plan is built with no clock: the audio context, the audio's power, building in the engine's context.

| | |
|---|---|
| `ClockedContext`, `ClockedContextOptions` | the audio context a plan is built in, made at a low latency from the browser's class handed in, and a clock's time put on its time, never into its past (`at()`), a sound due now starting with the next chunk (`context.ts`) |
| `EngineBuilding`, `BuildingIn`, `buildingIn()` | building in the engine's context, as an instrument is made at its first note: `into(into, draws?)`, once the audio runs, the Web Audio builder in the engine's context, into where it's told, its own draws where it has them, the time now the context's, a clock's time on it, the noise's buffers made with the first and shared by every one in that context; `buildingIn()`, in a context of its own, as an offline render asks (`engine-building.ts`) |
| `AudioPower`, `BrowserAudio`, `EngineOnceStarted` | the audio's power, started, paused and resumed as it's asked (`power.ts`): started, the engine made once in the browser's audio its owner hands in (`browser()`, `BrowserAudio`: its `AudioContext` class and iOS's audio session where there is one), iOS's audio session set for playback first, its context on the clock's time, what's built built by the Web Audio builder by the function handed in (its owner's `build()`, so it knows no desk), into the output after it, faded in, the clock's beat grid on the audio's time, then told (`onStart()`); once started, a start turns it back on; none while paused; built alone (`build()`), no clock and nothing told, as an offline render asks; paused, the output faded out and the context suspended once it's quiet (400 ms); resumed before that, faded in again from where the fade got to; after, faded in from silence and the context resumed, started if it hadn't; woken (`wake()`), back on after the browser stopped the sound, never started by it; `EngineOnceStarted`, the engine as its users ask for it: none until the audio starts |

Tested in node, in its `test/` folder, on a stand-in for Web Audio: the context on a clock (`context.test.js`), the power (`power.test.js`), building in the engine's context (`engine-building.test.js`).
