# spatial

Places, hearing by distance and the pointer's gestures. Part of [the libraries](../README.md).

- [`places/`](places/README.md): places perceived from where you are, a world that wraps round.
- [`hearing/`](hearing/README.md): hearing by distance, as values, no Web Audio.
- [`gestures/`](gestures/README.md): pointer input in, gestures out, no DOM.

Reads: `libs/base/` (`util`, `automation`); `gestures/` also `libs/sequencing/clock/`; `hearing/` and `gestures/` read `places/`.
