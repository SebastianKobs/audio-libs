# spatial

Places, hearing by distance and the pointer's gestures. Part of [the libraries](../README.md).

- [`places/`](places/README.md): places perceived from where you are.
- [`hearing/`](hearing/README.md): hearing by distance, as values.
- [`gestures/`](gestures/README.md): pointer input in, gestures out.

Reads: `base/` (`util`, `automation`); `gestures/` also `sequencing/clock/`; `hearing/` and `gestures/` read `places/`.
