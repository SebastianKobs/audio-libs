# web-audio-synth

The synth played in Web Audio: an instrument, MIDI 2.0's messages in (`libs/midi/`) and its notes out of its output, as a bass, a keyboard or a rack synth is one, since V3; a note played on a patch (`libs/synth/`), built by the engine (`libs/web-audio-engine/`) into where it goes, its controls taking clock times; and patches as they play, by name, each edit reaching every note of one that sounds. A package of its own since Z7, moved out of the tool (`tool/audio/voices/`), on MIDI's messages, the synth, the audio plan, the engine, the FX modules and the helpers (`libs/midi/`, `libs/synth/`, `libs/audio-plan/`, `libs/web-audio-engine/`, `libs/web-audio-fx/`, `libs/util/`), as `libs/web-audio-fx/` is for the effects. It knows no roles, no theme and no settings: the tool gives each track an instrument, a role's patch by its name, its knobs from the tweak panel, and patches its outputs into the desk (`tool/audio/studio/tracks/`).

A note's times are clock times, the engine's edge turning them into the context's, never in its past. It's planned from its patch with its context (a beat's length, a source of random draws) and its params, built from its time, and kept as it sounds by the patches it plays on, until its sources' last stop, so an edit to its patch reaches it (`sounding.ts`, G0.2b): planned again from the edited patch, with its note, its context, its random draws kept as they were drawn and its params, and moved there from now (`followEdit()`, `libs/audio-plan/`), a value glided there by 50 ms, an envelope taken on from where it is; a change of structure rebuilds it, a new voice planned as if it had started with the note, fading in over 0.1 s as the old one fades out. What a note was told since, its release, a control's set, a glide, is told a rebuilt voice too.

```ts
import { Instrument, Patches, playNote } from './index.ts';
const bass = new Instrument({ engine, patches, patch: 'pluck', beat: () => 60 / bpm, into: channel.input });   // its bank's pluck, patched into a desk
bass.receive([{ type: 'note on', index: 0, pitch: 40, velocity: 1, t }, { type: 'note off', index: 0, t: t + 0.5 }]);
const patches = new Patches({ patches: { pluck: pluckPatch }, now: () => engine.now() });
const controls = playNote(engine, patches, {
  patch: patches.of('pluck'),
  note: { pitch: 60, t: clock.now() + 0.05, velocity: 0.8 },   // held until it's let go: no duration
  context: { beat: 60 / bpm, random: Math.random },
  params: {},
  into: channel.input,
});
patches.set('pluck', { ...patches.current('pluck'), filter: { type: 'lowpass', freq: 1200 } });   // the note sounding glides there
controls.release(clock.now() + 1);                                                               // its note-off, a clock time
```

| | |
|---|---|
| `playNote(engine, patches, { patch, note, context, params, into })` | a note played on a patch as it plays (`play.ts`): `note`, its pitch, its time `t`, and where its patch reads them, its velocity (full unless given), its `duration` (with none held open until it's let go), a bend, a vibrato (held while it has one), its glides (`[[time, pitch]]`, clock times), a rise; returns its controls (`NoteControls`), taking clock times: `set(port, value, at, timeConstant)`, `release(at)`, a held note's `glide(pitch, at)` where its patch has it, and `stopped()`, whether its sources have all stopped by now, a held one never (V3) |
| `new Instrument({ engine, patches, patch, params, beat, random, answers, into, effects })` (`instrument.ts`), `receive(messages)` | an instrument, as a bass, a keyboard or a rack synth is one (V3): MIDI 2.0's messages in, a `Receiver` (`libs/midi/`), from a keyboard, a sequencer or whatever plays it; each note on a voice of the bank's patch by its name, `patch`, as the bank has it as the note starts, as MIDI's program change picks one, an edit reaching every note of it that sounds; held until its note off lets it go, one sent with it too; its own values sent with it as per-note controllers, `rise`, `bend`, `vibrato depth`, and its #3 Pitch changes its glides, a later one gliding a held note where its patch has a glide; `params()`, its knobs, `beat()`, a beat's length, and `random`, its draws (else `Math.random`), read as each note starts. Its notes out of its output, patched as it's made, `into`, a desk's channel, say, no node of its own (V4); the per-note controllers it `answers`, none unless it says, `brightness`, `volume`, `pan`, `effects 1 depth`, a stage of the note's own each, set as it starts, a later change gliding from its time, and with #91 Effects 1 Depth each note's room out of a second output, `effects`, as a multi-out synth's; #7 Volume with no stage for it on the voice's own out, times its patch's own volume, as a background's held note is hushed (P3b, V4); a note's stages let go as its sender detaches it (per-note management) or once its voice has stopped, as the next note starts. A track's controllers aren't its: whoever plays it maps them. Polyphony unlimited |
| `new NoteStages(engine, { into, room, heard, answers })` (`note-stages.ts`), `glide(controller, value, tc, from)`, `letGo()`, `HEARD_PER_NOTE`, `ROOM_PER_NOTE` | a note's own stages (G0b; the space's until V3, then `sound/space/`): its pan pot at `pan` as it starts, none for a note sent with none, its air's cutoff `brightness`, its dry gain `volume` into `into`, its room's gain `effects 1 depth` into `room`, taken after the air, each only where `answers` names it, every one unless it says; a voice plays into its `input`; a later change glides by its time constant, from `from` where it's to come; let go, each one's way out disconnected. The port of its stage's module each controller sets (`HEARD_PER_NOTE`, `ROOM_PER_NOTE`, Z1; the garden sent what its emitter set as them until N2); unused by the garden since N2, its notes on pools of tracks heard by their strips, kept for a keyboard's per-note controllers (M) |
| `new Patches({ patches, now })` | patches as they play, by name (`patches.ts`): copies of those it starts from; `now()`, the context's time, where an edit takes over |
| `of(name)` | a patch as it plays, the owner's own, not a copy, for a note to be played on; none for a name it hasn't |
| `current(name)`, `set(name, patch)`, `reset(name)` | a patch as a copy; set, it plays from its next note, and on every note of it that sounds, from now; reset, the one it started from |
| `Sounding`, `builtNote()` | each patch's notes that sound, until they've stopped, and a note built to be kept as it sounds (`sounding.ts`): what the patches and `playNote()` are made of |

Tested in node on the engine's stand-in for Web Audio, on a voice of its own (`test/web-audio-synth.test.js`, `test/instrument.test.js`, `test/note-stages.test.js`); the themes' instruments, played through the tool, in `mockup/test/unit/` (`follow-edits.test.js`, `sound-owner.test.js`) and held to their recordings (`instruments.test.js`).
